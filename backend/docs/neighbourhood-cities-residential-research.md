## Source limitations

Nominatim requests ran serially with a descriptive User-Agent and a 1.1-second pause after each completed response. Every received response, including an HTTP error followed by a successful retry, was cached. Reverse often returns an unnamed road with only governorate or enclosing city context; such an address does not establish a project name.

Live Overpass queries searched named objects within 1.2 km of gap centres. Three regional GET requests returned capacity HTTP 502 or URI-size HTTP 414; the equivalent alternative-server POST requests timed out without HTTP bytes. A small east-Port-Said bounding-box request also timed out. Cached error bodies and exact query URLs are in the manifest; network exception text is explicitly a diagnostic, not fetched dataset evidence. The notes distinguish service failure from proof that no named object exists. Original regional raw Overpass responses were still inspected offline for all 350 features.

Searches for east-Port-Said / Salam Misr developments established that named developments exist in that broader region, but supplied no source coordinate/boundary tying the far agricultural footprints to them. Searches for housing west of Sheikh Zayed's airport likewise did not identify a unique project at those block centres. No regional name was assigned through proximity. Raw micro-unit labels, private villas and generic housing labels remain excluded under their documented rules.
